# 제품 판단: Robot Task Lab

## 무엇을 만들었나

로봇 작업을 만들고, 실행하고, 배치를 바꿔 검증하는 브라우저 실습 도구다.
첫 화면부터 실제 작업실이 열리고 기본 작업을 실행할 수 있다.

기존 Physical AI Studio에서 가장 설득력 있었던 경험인
"눈앞의 로봇에게 작업을 시키고 결과를 확인한다"에 집중했다.
첫 구매자가 얻는 결과는 완성한 작업 파일, 반복 실험 결과, 수업에 쓸
시각적 실습이다.

## 첫 구매자 가설

1. 로봇 기초 실습을 준비하는 소규모 강사와 교육 크리에이터.
2. 설치 부담 없이 조작과 작업 순서를 익히려는 입문자.
3. 로봇 관련 강의나 영상에서 재현 가능한 데모가 필요한 제작자.

이 가설은 아직 인터뷰나 결제로 검증하지 않았다. 현재 구현이 시장 수요나
매출을 증명하지는 않는다.

## 판매 후보

무료 색상 분류 실습을 공개하고, 더 깊은 과제와 수업 자료를 묶은
일회성 $29 Lab Pack을 우선 검증한다. $79 Instructor Pack은 실제 교육자
수요를 확인한 뒤 검토한다. 두 가격 모두 테스트할 가설이다.

유료 구매 이유는 새 로봇 모델의 숫자보다 다음 결과물에 있다.

- 난이도 순서가 있는 12개 이상의 완성된 실습.
- 실패 원인과 수정 과정을 포함한 예제 작업.
- 강사가 바로 사용할 수 있는 과제, 해설, 평가 기준.
- 재현 가능한 실험 파일과 결과 보고서.

현재 세 가지 실습은 모두 열려 있다. 검증되지 않은 구매 버튼이나
작동하지 않는 결제 화면은 구현하지 않았다.

## 구현 범위

- 색상 분류, 정밀 배치, 3단 쌓기.
- 카드형 작업 순서와 수정, 활성화, 추가, 삭제, 되돌리기.
- 실제 강체 물리와 최종 위치 기반 성공·실패 판정.
- 서로 다른 배치 10개에 대한 검증과 CSV 결과.
- 로컬 저장, 프로젝트 재가져오기, Python dry-run 내보내기.
- 데스크톱과 모바일 작업 화면.

현재 자연어 AI, 실제 하드웨어 제어, 강화학습은 없다.
그 기능들은 별도 범위다. 현재 제품의 화면과 문서는 있는 기능만 표시한다.

## 기술적 경계

로봇 팔은 역기구학으로 움직이며 블록의 중력·충돌·관성은 cannon-es로 계산한다.
집기는 제약 조건으로 붙잡는 근사 모델이다. 팔 링크의 충돌, 실제 모터,
토크, 마찰 기반 파지, 센서 지각, 실물 로봇의 좌표계 변환을 검증하지 않는다.
따라서 실제 장비 제어용 파일이라고 판매하면 안 된다.

## 다음 투자 판단

색상 분류의 15~30초 실행 영상, 공개 실습, 실험 파일을 한 흐름으로 보여준다.
로봇 교육 커뮤니티와 소규모 강사에게 실습을 제공하고 실제 수업 준비 시간을
줄이는지 확인한다. 모집 규모, 전환율, 예상 매출은 아직 추정하지 않는다.

첫 검증에서는 "신기하다"보다 다음 신호를 본다.

- 사용자가 직접 작업을 수정하고 다시 실행하는가.
- 실험 파일이나 결과를 저장해서 다시 사용하는가.
- 강사가 다음 과제나 수업 자료를 구체적으로 요구하는가.
- 자료가 포함된 유료 팩에 실제 결제 의사를 보이는가.

이 신호가 없으면 로봇 종류나 AI 버튼을 늘리는 개발을 중단한다.
신호가 있으면 과제와 해설을 보강하고 유료 팩을 구성한다.
