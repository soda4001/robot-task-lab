# 실행과 사용

`D:\robot-task-lab\start-lab.cmd`를 더블 클릭한다.
처음에는 의존성을 설치하고 브라우저를 연다. Node.js 22 이상이 필요하다.

현재 실행 주소는 `http://127.0.0.1:5180`이다.
다른 프로그램이 같은 포트를 쓰면 실행 창에 표시되는 다음 포트를 이용한다.

## 먼저 볼 것

1. 첫 화면 중앙 아래의 **Run**을 누른다.
2. 로봇이 세 블록을 각 색상의 트레이로 옮기는지 본다.
3. 아래 **Validation**에서 최종 위치 오차와 성공 여부를 확인한다.
4. 오른쪽 **Runs > Test 10 layouts**로 배치를 바꾼 검증을 돌린다.

## 직접 바꿔 보기

- 왼쪽 작업을 선택하면 오른쪽에서 블록과 목적지를 바꿀 수 있다.
- 카드 아래 위·아래 화살표로 순서를 바꾸고 체크박스로 작업을 건너뛴다.
- **Placement offset**을 바꾸면 목표 위치에서 떨어뜨리는 오차를 조절한다.
- **Layout seed**와 섞기 아이콘으로 초기 물체 배치를 바꾼다.
- **Lab library**에서 정밀 배치나 쌓기 과제로 이동한다.
- **Build from recipe**에서 기본 작업 순서를 다시 구성한다.
- 실행 중 설정을 바꾸려면 먼저 리셋한다. 일시정지 상태에서는 재개할 수 있다.

## 파일과 결과

프로젝트는 현재 브라우저에 자동 저장된다. 다른 브라우저나 컴퓨터로 옮길 때는
**Export > Project JSON**을 다운로드한 뒤 가져오기 아이콘을 사용한다.
작업 이름 오른쪽의 저장 아이콘도 같은 프로젝트 파일을 내려받는다.

**Python recipe**는 Python으로 실행 가능한 dry-run 파일이다.
실물 로봇을 움직이지 않고 작업 명령을 출력한다.

실험 결과는 **Runs**의 다운로드 아이콘으로 CSV로 내보낸다.
3D 화면 오른쪽의 캡처 아이콘은 작업실 PNG 이미지를 다운로드한다.

모바일에서는 위쪽 **Scene / Program / Inspect** 탭으로 화면을 전환한다.

제품 판단과 다음 유료화 검증 방향은 `PRODUCT_DIRECTION.md`에 있다.
